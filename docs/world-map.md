# 海难、猪镇配置与地图兼容

世界配置读取上传 Lua 的顶层 `location`，再用对应的海难、猪镇或火山字段分组展示。它独立于森林/洞穴进程类型，不改变端口和运行目录。原版字段继续使用已有 DMP 定义；每个上传参数只显示一次。

已知模组字段展示中文标签及真实选项，当前值即使不在选项表中也保留。未知字符串、数字、布尔值可直接编辑，嵌套表或空值使用 Lua 编辑入口；不执行上传的 Lua，也不虚构未知字段的合法选项。修改已有值时保留其他参数与注释。切换到原版森林/洞穴模板仍会经过确认。

猪镇存档包含室内房间，旧逻辑可能先读到室内尺寸。地图读取现限定到序列化主地图表的直接字段，跳过嵌套房间、字符串、注释及函数引用；使用有深度限制的词法扫描，不执行存档代码，也不为多 MB 存档构造完整 AST。

2026-10-22 验证：Linux Docker 全套 132 项通过；四层 override 数量依次 183、108、196、196，线上均完整显示。浏览器实际显示猪镇 1935×1935 图像，原房间配置和四层运行状态保留。只读隔离渲染猪镇约 2 秒；这个时间不含公网传输或首次动态材质采集，不能作为所有部署的加载保证。线上缓存请求时间另记于 verification.json。

部分动态模组地块尚无可用材质：当前猪镇 8 个、海难 6 个，页面会列出提示；其他两层本次未报告缺失地块。地图能加载不代表所有第三方模组地形已覆盖。未进行真实游戏客户端入房验收，未修改第三方蓝图代码。

## 直接选择世界类型

2026-10-23 起，「房间配置 → 世界配置」每层可选择森林、洞穴、海难、猪镇，无需上传或编写 Lua。选择海难或猪镇后确认替换当前层配置，再调整可视化选项并保存设置。目录与直连端口保留；模组世界与原有基础进程类型分开保存。

生成模板参考服务器上 Island Adventures 海难与猪镇模组注册的 location、task_set、start_location、layout_mode 等定义，并使用已有模式模板的公共生存规则。海难和猪镇支持无尽、生存、轻松、荒野、暗无天日；熔炉与暴食会明确拒绝，不会套用错误生成模板。「应用当前模式预设」保留所选扩展世界类型；个人预设按实际世界类型保存、筛选。

面板仅生成配置，不自动安装或启用模组。海难需要对应 Island Adventures 海难模组及 Core，猪镇需要对应猪镇模组及海难、Core 等依赖。这里兼容当前已核对的 Island Adventures 定义，不能承诺不同作者或未来版本的所有世界模组采用相同字段。配置生成无需 Steam API Key。

地形参数只对新生成世界生效，已有存档不会因为选择类型而变成海难或猪镇。切换会替换当前层世界配置并要求确认，不删除或重置任何存档。已有世界需另行新建或重置才能生成新地形。

验证：Linux 候选镜像全套 134 项通过，无失败、无跳过；本地浏览器验证取消、生成、可视化与代码往返、模式预设、分类预设、目录端口保留及手机布局。线上验证四类选择、新模板生成、原四层完整字段、390px 布局，无配置写入与脚本错误；游戏 PID、已保存房间配置逐项保持一致。未用生产存档测试重置或进行真实新档生成、游戏客户端入服验收。

部署使用前端热更新，正在运行的容器基础镜像仍是 `feather-panel:world-map-20261022`；已构建并测试完整候选镜像 `feather-panel:world-picker-20261023`，实际根 compose 已指向该镜像供下一次重建使用。本次没有重建容器或停止游戏。源码、发布 ZIP 与文档同步；镜像未推送到公共仓库。

## 火山世界选择与可视化配置

在「房间配置 → 世界配置」中选择任意层的「火山 · 需要世界模组」，确认后生成静态 Lua 配置。模组管理需启用 Island Adventures Shipwrecked（1467214795）及 Core（3435352667）等当前模组要求的依赖；面板不会自动安装或启用模组。切换只修改当前浏览器中的待保存配置，端口、世界目录及服务端基础进程类型保留。已有存档地形不会改变，火山生成规则仅对新世界生效。

根据已安装模组当前有效的 `scripts/map/sw_locations.lua`、`scripts/map/tasksets/volcanoset.lua`、`scripts/map/startlocations/volcano.lua` 与 `scripts/map/levels/volcano.lua` 注册：location 为 `volcanoworld`，任务集为 `volcano`，出生点为 `volcano_default`，预设 ID 为 `SURVIVAL_VOLCANO_CLASSIC`，小型地图、无海洋，背景节点范围 `{0,0}`。不采用文件中 Deprecated 注释块的旧 `VolcanoPortal` 出生点。五种生存玩法通过面板组合公共生存规则，火山地形与出生点保持一致。

可视化包含岩浆矿、咖啡丛、象仙人掌、黑曜石矿、木炭矿、火山灌木、龙骑士、龙骑士蛋、资源再生和热带季节等，复用模组原有图标。海带、海豚、海浪、海难同图火山岛等不加入火山默认模板。用户上传的额外或未知字段继续保留并可编辑；缺少顶层 location 但具有 `task_set="volcano"` 的配置也能识别。世界预设按火山独立归类，可视化与 Lua 双向编辑保留字段。

## 火山首次启动退出的修复

当前 Caves4 火山日志在启动约 27 秒时出现 `scripts/shardindex.lua:347: Level data override is invalid!`。从当前服务端 `data/databundles/scripts.zip` 读取实际 `GetLevelDataOverride` 代码确认，其断言要求 `id`、`name`、`desc`、`location`、`overrides` 均存在。面板先前新生成的扩展世界模板漏了 `desc`，静态 Lua 语法与参数测试未覆盖游戏这项元数据断言。海难、猪镇、火山生成模板现在统一写入 desc，新增覆盖全部三类扩展世界与五种模式的回归。

已备份当前房间 JSON、Caves4 配置和失败日志，仅在 Caves4 的 Lua 中补上 desc，同时事务更新数据库中同一配置。其他四层配置和进程保持不变。当前火山仍关闭，尚未验证后续实际地图生成与游戏加入；不能将本次字段修复等同于已完成火山启动验收。模板两文件热更新，Linux 镜像 137/137 测试通过，无失败或跳过；下一次重建镜像为 `feather-panel:volcano-desc-20261023`，当前运行容器基础镜像仍为 `feather-panel:world-map-20261022`。
