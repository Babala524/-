# 面板安全加固（2026-10-23）

## 已实现

- 浏览器使用每次登录随机生成的独立会话，数据库只存 HMAC 摘要。服务端强制 12 小时到期，退出立即删除该会话。最多保留 100 个会话；修改管理员密钥后，旧会话失效。
- 旧版固定浏览器 Cookie 不再接受，升级后需要重新登录；管理员密钥本身未更换。已有 Bearer API 调用继续有效。
- 登录按连接来源每分钟最多 10 次，不信任客户端伪造的转发 IP。来源记录设容量上限，过期清理。共享 IP/NAT 用户会共用该限额。
- 拦截跨站及不同协议 Origin 的请求，浏览器 Cookie 使用 HttpOnly、SameSite=Strict。
- HTML 使用随机 CSP nonce，内联事件只允许随页面发布的哈希；禁止任意新增内联脚本、嵌入框架、插件、外部表单目标和外部数据接口连接。
- API JSON 必须是对象；文件上传与共享库投稿共用两个并发名额，失败/结束释放。原有压缩包大小、解压字节数、文件数、重复路径、符号链接、目录穿越限制继续保留。
- 管理员密钥文件权限收紧为 0600；保留非 root 容器用户，不修改游戏端口与存档。
- 顶部右侧提供退出登录按钮。
- 支持 Docker 首次部署创建管理员账号：初始化密钥保存在数据卷 `/data/setup-key`，成功创建后立即删除；账号密码哈希和账号状态保存在 `/data/panel.sqlite`，密码不会明文落盘。
- 登录页同时支持账号密码和旧管理员密钥。默认关闭陌生人自助注册；需要开放注册时设置 `FEATHER_ALLOW_REGISTRATION=1`，生产环境建议由管理员创建账号。
- 账号会话与用户关联，停用账号或修改密码会撤销该账号的旧会话；旧 Bearer 管理员密钥接口继续兼容。
- 账号角色分为管理员和操作员：操作员可以登录并操作已授权的面板功能，但账号管理、共享模组审核/取消发布/移除等管理动作只允许管理员。

## HTTPS 与边界

当前 NAT 部署仍为 HTTP。应用层修复不提供传输加密，HTTP 上的管理员密钥和会话仍有被链路窃取的风险。公网使用建议配置 HTTPS；需要域名或能提供 TLS 的入口。未擅自改成 HTTPS 或更改现有端口。

若部署者已经使用 HTTPS 反代，设置 `FEATHER_SECURE_COOKIE=1`，使浏览器只通过 HTTPS 发送会话 Cookie，同时按 HTTPS 校验 Origin。HTTP 直连应保留默认值 0；不自动信任用户传来的 X-Forwarded-Proto。

游戏及模组由同一容器用户运行；模组实际启动后是游戏代码，不能把非 root 等同于模组沙箱。管理员只应启用可信模组。共享库投稿仍须管理员人工审核后才公开，本次没有更改已发布条目或自动发布任何模组。

这是针对已确认问题的修复，不等于无漏洞保证，也没有声称完成第三方渗透测试、主机系统修复或 DDoS 防护。
