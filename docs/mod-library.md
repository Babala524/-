# 隐藏模组收录与共享库

2026-10-22：支持上传、收录和重新安装工坊隐藏、下架、无法下载的完整模组包。需要保留原来的工坊数字 ID，通常可从 `workshop-ID` 文件夹或原工坊地址中取得。完全没有工坊 ID 的本地目录模组尚未支持。

## 使用方法

1. 在“模组管理 → 下载模组”点击“上传模组 ZIP”，填写原工坊 ID。压缩包可以直接包含 `modinfo.lua`、`modmain.lua` 和资源文件，也可以有一层或多层外部文件夹。一次上传一个完整模组。
2. 上传后保存在本地收录库，并安装到游戏模组目录。运行中的模组替换会暂存到重启时应用。上传不会自动启用房间中的模组。
3. 对已经手工放到游戏目录的模组，可以在“已安装的模组”点击“收录共享”，保留完整 ZIP 和名称、作者、版本记录。
4. “下载模组”的来源可以选择“创意工坊”“本地收录”“共享模组库”。卸载已安装文件后，本地收录里的包仍可重新安装；要删除保留的包，进入“收录与共享”移除收录。
5. 需要共享时，在“收录与共享”确认作者允许公开分发后手动提交。共享库管理员下载审核、批准发布后，其他部署者才能搜到和下载。管理员可以拒绝或下架。

共享库收录不会恢复 Steam 上的工坊页面，也不会修改模组脚本来修复蓝图或其他游戏兼容性问题。需要客户端安装的隐藏模组，玩家仍需要自行安装匹配的客户端文件；面板的共享库用于服务器模组安装。

## 部署配置

正常部署的面板是共享库客户端；默认地址为当前托管服务器 `http://202.189.15.98:35555`。在 Docker Compose 的 `.env` 中设置：

```dotenv
FEATHER_MOD_REGISTRY=http://202.189.15.98:35555
FEATHER_MOD_REGISTRY_HOST=0
FEATHER_MOD_LIBRARY_MB=4096
```

只有托管共享库的那台服务器设置 `FEATHER_MOD_REGISTRY_HOST=1`。服务与面板共用监听端口和数据卷，不需要另加端口映射或反向代理。换用自己的共享库时，所有客户端改为相同的服务根地址，不能填写到 `/registry/v1` 路径。可以设置空的 `FEATHER_MOD_REGISTRY` 禁用外部共享库查询；Steam 查询和本地收录继续独立工作。

其他人需要使用包含此功能的新版面板。共享搜索、提交和首次下载依赖托管服务器保持在线；已安装或本地收录的副本继续保留。管理员口令只用于登录自己的面板，不发送到共享库。旧版面板不会自动获得这些功能。

## 存储与约束

- 单包 ZIP 最大 512 MiB，解压最多 2 GiB、20,000 个路径。拒绝路径越界、链接、设备文件、重复路径、加密 ZIP 和缺失关键文件的包。
- 本地库和托管库共用 `/data/mod-library`，默认保留包总容量 4 GiB，可用 `FEATHER_MOD_LIBRARY_MB` 调整。公开托管会持续消耗磁盘和下载流量。
- 公共提交每个来源 IP 每小时最多 3 次，同时只接收一个包；待审核最多 20 个、总容量至多 2 GiB。队列满时应先处理审核或拒绝不需要的提交。
- ZIP 保留在数据卷中，未加入面板镜像和发布源码 ZIP。提交前不会自动向第三方共享任何已有模组。未审核的包不能从公开下载接口取得。
- 安装包使用 SHA-256 校验，大小或校验值不符时不安装。模组元数据通过静态语法读取，面板不执行上传的 Lua。审核和测试兼容性仍由托管管理员负责。
- 上传/共享版本使用独立版本来源，避免 Steam 自动更新覆盖它们。替换版本需要重新上传，或在共享库选择发布的版本重新安装。
