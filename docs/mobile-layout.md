# 手机布局与动态壁纸

2026-10-23 更新。

手机使用 `assets/wallpaper-mobile.mp4`（1280×720、24 fps、H.264 Main Level 3.1、YUV420P、无音轨），文件 5,864,178 字节。原桌面视频是 3840×2160、60 fps，文件 61,162,929 字节。手机版包含相同的完整 30 秒循环，文件起播索引前置。选择手机资源后，不再先请求桌面视频。选择依据是初次打开时屏幕宽度不超过 760px，或主要指针是触摸；旋转屏幕不重新下载视频。

`assets/wallpaper-poster.jpg` 提供加载前的背景。视频保持静音、内联和循环播放。浏览器限制自动播放、视频暂停或加载失败时，右上角出现播放按钮；点击可重新播放或重新加载。切回页面时尝试恢复。低电量模式或浏览器限制仍可能要求用户点击，页面不会假装视频已经播放。

竖屏顶部八个入口排列为四列两行。实时控制按钮排列为两列；房间配置、模组、日志、存档、玩家管理的子选项及操作区适应窄屏。多层世界切换按两列显示，首页世界概览标签自动换行。页面使用动态视口高度及安全区域留白；触摸滚动不再触发跨页面拖动。桌面仍保留原有拖动操作。

本地与线上使用 Chromium 的移动设备仿真验证 320、360、390、430px 竖屏及 844px 横屏，包含七个页面、17 个子页面、九个通用弹窗和五个概览详情。验证视频时间持续增加、部分 HTTP 下载响应及自动播放拒绝后的按钮恢复。未用实体 iPhone、Android 或 Safari 验证；特定浏览器有差异时应保留对应机型及版本信息继续检查。

Dockerfile 已通过 `COPY assets/ assets/` 包含这些资源，不需要额外映射目录或安装转码软件。更换视频时需同时重新生成手机版和封面；转码工具只在开发时使用，不包含在部署镜像中。
